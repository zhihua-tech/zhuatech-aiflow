## 本次升级：工作流在途重试与执行槽位预算

计算新任务、在途任务和失败重试的执行槽位占用，限制同时活跃与最大尝试总数，副作用重试需要幂等声明。只做容量核验。

新增已认证的结构化录入工作台（`/operations.html`），支持批量核算、逐条结果依据、分级复核和CSV/完整JSON导出。结果由真实后端算法计算，不是预置演示数字。所有数值精确传递，不调用外部模型。

这是**只读核算**：不写库、不审批、不自动执行财务、签署、销毁或设备控制。输入条件满足不是执行授权。[算法、输入边界与接口说明](docs/OPERATIONS-REVIEW.md)。
## 产品概览

AIFlow 不只是聊天界面，而是一套把模型推理、企业工具、流程节点、人工审批和安全审计组织起来的智能体运行平台。业务团队可以配置目标、工具权限与工作流，平台负责状态追踪、失败重试、成本统计和高风险动作拦截。

## 一条受控的执行链路

```text
业务事件 → 意图规划 → 工具调用 → 条件分支 → 人工确认 → 结果归档 → 运行评测
```

- 智能体角色、目标、模型参数、提示版本和工具白名单
- 可视化工作流语义：节点、分支、循环、并行、重试和补偿
- API、数据库和内部系统工具目录及最小权限授权
- 人工审批、敏感动作确认、异常接管和全过程审计
- 运行链路、时延、令牌、成本、成功率与业务收益分析
- 场景评测、版本门禁、灰度发布与安全策略

新增的工作流发布校验会检查重复步骤、未登记工具、外部写操作审批和最小权限风险。校验不通过时返回明确错误清单，阻止有风险的流程进入执行队列。

工作流影响分析进一步比较新版本与运行基线，估算每日模型令牌、重试放大效应和人工复核工时；当复核产能不足时直接标记为阻断，避免“流程能发布、运营接不住”的上线风险。

## 输入对照与版本化快照

在既有「工作流在途重试与执行槽位预算」基础上，新增 `/comparison.html`：基准与候选两组数据都由当前真实算法重算，按编号展示新增、移除、逐字段变化和精确数值差，支持筛选、分页和全量导出。原核算入口可导出输入快照，对照页经后端完整校验后整体导入；失败不覆盖当前输入。

快照区分项目、字段契约及算法版本。建议较宽松不代表风险已下降，输入摘要不是签名；操作人和时间仅为响应元数据，不是持久化审计。本次未新增模型调用或业务写入，也不代表全系统生产认证。详见[输入对照操作与接口说明](docs/INPUT-COMPARISON.md)。
